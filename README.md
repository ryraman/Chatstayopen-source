# ChatStayOpen

Client-side Fabric mod for Minecraft 1.21.11: the chat stays open after pressing ENTER, the input is cleared and you can keep typing. ESC still closes the chat.

## Build
Requires JDK 21.

    ./gradlew build

The jar is created in build/libs/chatstayopen-1.0.0.jar. Requires Fabric Loader and Fabric API.
